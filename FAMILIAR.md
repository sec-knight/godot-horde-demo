# Project Context

This repository is extra source for **sneaker-games-site**. [sec-knight/sneaker.games](https://github.com/sec-knight/sneaker.games) remains the public/admin deploy destination. Canonical architecture lives in the private repo [sec-knight/sneaker.games.plans](https://github.com/sec-knight/sneaker.games.plans).

It holds the public Three.js remake of Horde Defense. Built artifacts feed sneaker.games `games/horde-defense` (public) and `admin/horde-three` (deploy bundle). Play, feel targets, and controls are in `README.md`.

Durable intent, constraints, structure, and current execution state are **not** recorded here. Before substantial work, read `architecture/` and `activity/CURRENT.md` in sneaker.games.plans.

This file and `AGENTS.md` explain how to operate this extra-source repository. They must not become a competing architecture canon.
